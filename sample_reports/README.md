# Biomvira — Synthetic Diagnostic Laboratory Reports

This directory contains realistic blood report PDFs generated by `evaluation/synthetic_generator.py` mimicking major Indian diagnostic chains.

You can drag and drop these PDFs directly into the Biomvira web app at `http://localhost:8000`:

| File | Lab Chain | Clinical Scenario | Markers Included |
|---|---|---|---|
| `report_01_lal_pathlabs_low_vit_d_and_iron.pdf` | Dr. Lal PathLabs | Moderate Vitamin D (11.2 ng/mL) & Iron/Ferritin (8.5 ng/mL) deficiency | Vit D, Ferritin, Hb, Calcium |
| `report_02_metropolis_b12_and_folate_deficient.pdf` | Metropolis Healthcare | Low Vitamin B12 (132 pg/mL) & Borderline Folate (3.1 ng/mL) | B12, Folate, Vit D, Calcium |
| `report_03_srl_severe_anemia_critical_hb.pdf` | SRL Diagnostics | **Severe Anemia & Critical Warning**: Hb (7.4 g/dL), Ferritin (5.8 ng/mL) | Hb, Ferritin, Vit D, Folate |
| `report_04_apollo_comprehensive_6_markers.pdf` | Apollo Diagnostics | Full comprehensive panel with all 6 biomarkers | Vit D, B12, Folate, Ferritin, Hb, Calcium |
| `report_05_thyrocare_alternate_si_units.pdf` | Thyrocare Technologies | International/SI units (`nmol/L`, `pmol/L`, `g/L`, `mmol/L`) testing unit conversion | Vit D, B12, Hb, Calcium |
| `report_06_optimal_healthy_profile.pdf` | Max Healthcare | All 6 biomarkers in optimal reference range (healthy adult) | All 6 markers (Normal) |

---

### How to re-generate or create more reports:
```bash
python3 evaluation/synthetic_generator.py
```
